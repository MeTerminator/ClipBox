# Tauri 检查记录（2026-10-09）

本轮以桌面原生层为重点；未修改 Web 前端或 Go 后端业务代码。审查包括 IPC 权限、导航、持久化、下载、上传、剪贴板、图标和便携包构建。以下为代码审查与本机验证结果，不等同于完整渗透测试。

## 已修复

- 将五个自定义 Rust 命令纳入 Tauri ACL，只授权主窗口；悬浮窗只保留事件监听和窗口拖动，主窗口保留上传结果事件发送。
- 阻止受信任 WebView 导航到外部站点；主窗口的 HTTP(S) 新窗口链接交给系统浏览器；不允许 file/custom scheme 新窗口。
- macOS 持久化数据的初始化脚本先检查页面来源，避免后续外部页面加载时恢复房间令牌等本地数据。
- 房间下载只接受已由主窗口登记的服务端 origin 和 `/api/rooms/{5位数字}/messages/{数字}/file` 路径，保留主服务与直连服务回退。拒绝 URL 凭据、片段及额外查询参数；原生网络请求不跟随重定向。
- 网络请求增加 15 秒连接超时、60 秒读取空闲超时。此处未设置整个大文件传输的总时长限制。
- 本地存储写入串行化、落盘同步，Unix 新建存储临时文件权限为 0600，随后原子替换。持久化内容仍为明文，不是系统钥匙串加密。
- 退出或切换房间时清空原生剪贴板缓存，避免继续粘贴上一房间内容。
- 验证上传 ID、分块大小的整数转换；检测上传文件缩短；检查普通文件类型。没有声称解决文件在哈希和上传期间所有可能的并发修改。
- 使用 `frontend/public/favicon.svg` 原样生成 PNG、ICO、ICNS，替换桌面图标；macOS 便携可执行文件在运行时设置 Dock 图标。
- 将已撤回的间接依赖 `yoke-derive 0.8.3` 更新到 `0.8.4`。

## 验证

- Rust 单元/回归测试 6 项通过：快捷键判断、下载 URL 边界、导航来源、禁止重定向、Windows 文件名清理、并发同名下载不覆盖。
- `cargo clippy --locked --lib -- -D warnings` 通过；Rust 格式及 Git diff 空白检查通过。
- 前端类型检查、Go 全部测试、便携包脚本 3 项测试通过。
- 本机 macOS 正式桌面构建通过；图标 PNG 已目视检查与 Web SVG 一致。
- 未进行 Windows/Linux 真机交互测试，也未在本轮验证实际系统复制/粘贴、辅助功能授权和 Dock 显示效果。

## 尚存风险与边界

1. **Linux 上游依赖告警**：`cargo audit` 的 vulnerabilities 分类为 0，但另有 `glib 0.18.5` 的 `RUSTSEC-2024-0429`（`VariantStrIter` 迭代器健全性/内存安全问题），以及 6 项 unmaintained 告警。glib 由 Tauri/GTK3 链路引入，本项目未直接使用该迭代器；没有据此认定它不可触发，也没有强行替换成不兼容的 glib 大版本。
2. **Windows/Linux 粘贴时序**：仍使用 rdev 监听快捷键，没有 macOS 同步 event tap 的“先写剪贴板再交付按键”保证；目标应用可能先读取旧剪贴板。Linux 依赖 X11，Wayland 不应视为已支持。
3. **自动下载资源消耗**：房间成员发来的文件会自动写入本机，尚无桌面下载总配额和用户确认。恶意成员大量发送文件可能占满磁盘；本轮没有改变既有自动同步产品行为。
4. **便携数据安全**：macOS 房间令牌随应用存储明文保存。0600 限制其他普通 OS 用户读取新建文件，但不防同一 OS 用户下的其他进程；分享便携目录时不能连同 `data/` 分享。
5. **后端密码与限速（仅记录，未改代码）**：房间密码使用通用 SHA-256 摘要函数，缺少盐和慢哈希；未在应用路由中发现加入房间的尝试限速。如果数据库泄露，弱密码易被离线猜测；公网部署还需要核实网关是否已限制在线尝试。对应 `internal/share/service.go` 的 `JoinRoom` / `SetRoomPassword` / `TokenDigest` 和 `internal/server/server.go` 的路由注册。
6. **信任边界**：后端 origin 由受信任主窗口登记，属于对返回文件 URL 的约束，不能宣称可抵御主窗口被完全控制后的任意网络操作；远程 HTTP 后端仍允许使用，以兼容本地/LAN 部署。
